## 音频生产流水线（新建）

位置：`D:\小程序开发\workbud_tingshu\pipeline\`

### 架构
```
书名列表 → 图书数据(阿里云API) → AI文稿(豆包) → TTS音频(火山引擎) → JSON数据包
```

### 关键文件
- `config.yaml` - 配置（API密钥等）
- `main.py` - 主入口
- `modules/pipeline.py` - 流水线调度（并发/断点续传）
- `modules/book_info.py` - 图书数据获取
- `modules/content_gen.py` - AI文稿生成（豆包API）
- `modules/tts_synth.py` - TTS音频合成（火山引擎）
- `modules/data_storage.py` - JSON数据存储
- `output/` - 输出目录（data/JSON、covers/封面、audios/音频）

### 依赖
- `pip install "volcengine-python-sdk[ark]" pyyaml requests`

### 使用
1. 编辑 `config.yaml` 填入API密钥
2. 编辑 `book_list.txt` 放入书名列表
3. 设置 `config.yaml` 中 `test_mode: false`
4. `python main.py`

### 项目结构
```

├── src/
│   ├── pages/          # 7个页面
│   ├── components/     # 10个组件
│   ├── stores/         # player/user/book

│   └── styles/         # 公共样式

├── server/
│   ├── src/

│   │   ├── models/     # 数据模型（book/quote/category/user/favorite/history）
```
