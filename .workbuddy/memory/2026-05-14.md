## 音频自动化生产流水线（2026-05-14 傍晚）

### 合规方案设计
用户确认：先上传字幕/文字稿，再用TTS朗读。这样产品定位为"TTS工具"而非"有声书平台"，更容易通过备案。

### 流水线架构
```
文字稿 → edge-tts生成音频 → 小程序播放 + 字幕同步
```

### 存储空间计算
- 每本书约4500字字幕 → ~22KB/书
- 1000本书 ≈ 22MB ✅

### 已创建文件

位置：`D:\小程序开发\workbud_tingshu\pipeline\`

1. **crawler.js** - 书籍爬虫
   - 支持豆瓣读书爬取
   - 本地缓存已爬取书名，避免重复

2. **script_generator.js** - 字幕生成服务
   - 调用豆包API生成4500字字幕文稿
   - 支持模拟模式（测试用）

3. **tts_service.js** - edge-tts TTS服务
   - 默认音色：zh-CN-YunxiNeural（深夜播客男声）
   - 语速：-10%，音调：-5Hz
   - 支持批量合成

4. **pipeline_runner.js** - 集成流水线脚本
   - 一键运行完整流程
   - 支持分步骤运行

5. **package.json** - 依赖管理

### 数据库设计文档

位置：`D:\小程序开发\workbud_tingshu\docs\books_collection_design.md`

**books集合字段：**
- 基础信息：title, author, category, categoryName
- 出版信息：publisher, isbn, publishDate
- 字幕：script(~4500字), sentences[], scriptLength
- 音频：audioUrl, audioDuration, isAudioGenerated
- TTS参数：ttsVoice, ttsRate, ttsPitch
- 状态：isHot, isGenerated, isPublished
