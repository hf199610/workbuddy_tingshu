## 完整处理流程（以围城为例）

### 步骤1：下载封面图
```bash
# 方法1: 使用脚本自动下载
python download_covers.py --book "围城"

# 方法2: 手动下载（需要添加Referer头）
httpx + headers 模拟浏览器访问
```

### 步骤2：运行Pipeline生成音频
```bash
cd pipeline

# 处理围城（-force 强制重新处理）
python full_pipeline.py --book "围城" --force

# 或自动处理Excel中的书籍列表
python full_pipeline.py --count 10
```

### 步骤3：导入云数据库
```bash
# 修复导入问题
python import_book.py
```
