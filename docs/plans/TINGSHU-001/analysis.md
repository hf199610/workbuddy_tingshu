## 一、需求概述

### 1.1 产品定位

**产品名称**: 听书金句  
**产品类型**: 微信小程序  
**核心价值**: 为用户提供经典书籍的精华讲解和名人金句，让用户可以在碎片化时间内高效获取书籍核心内容。

### 1.2 目标用户

- 喜爱阅读但时间有限的职场人士
- 希望快速了解经典书籍内容的用户
- 喜欢收藏和分享金句的用户群体

### 1.3 核心功能矩阵

| 功能模块 | 功能点 | 优先级 | 说明 |
|---------|--------|--------|------|
| 首页 | 搜索 | P0 | 全局搜索入口 |
| 首页 | 热门推荐 | P1 | 轮播展示精选书籍 |
| 首页 | 每日金句 | P1 | 每日推荐一条金句 |
| 首页 | 快速入口 | P1 | 快捷导航到主要功能 |
| 首页 | 最新讲解 | P2 | 新书上架展示 |
| 书籍 | 列表浏览 | P0 | 分类筛选+网格展示 |
| 书籍 | 详情查看 | P0 | 书籍信息+简介+金句 |
| 金句 | 列表浏览 | P0 | 金句瀑布流展示 |
| 金句 | 金句操作 | P1 | 播放+复制+收藏 |
| 播放器 | 音频播放 | P0 | 全屏+迷你播放器 |
| 个人中心 | 用户信息 | P1 | 登录+展示 |
| 个人中心 | 我的收藏 | P2 | 收藏书籍列表 |
| 个人中心 | 播放历史 | P2 | 最近播放记录 |
| 个人中心 | 设置 | P3 | 关于我们等入口 |

> **需求变更 (2026-05-13)**: 首页移除书籍分类标签，金句页移除筛选排序栏

## 二、功能模块详解

### 2.1 首页模块 (page-index)

#### 2.1.1 搜索栏
- **位置**: 页面顶部，深色渐变背景
- **交互**: 点击打开搜索覆盖层
- **状态**: 默认显示"搜索书名/作者/金句"提示

#### 2.1.2 热门推荐轮播
- **样式**: 圆角卡片，高度140px
- **内容**: 书籍封面+标题+副标题
- **交互**: 点击进入书籍详情
- **展示数量**: 至少1条，可扩展多条

#### 2.1.3 每日金句卡片
- **样式**: 紫色渐变背景
- **内容**: 金句文本+来源（作者+书名）
- **交互**:
  - 点击金句文本 → 打开播放器朗读
  - 刷新按钮 → 随机切换新金句
  - 复制按钮 → 复制金句到剪贴板
  - 分享按钮 → 分享金句（模拟）
- **数据**: 从金句库随机抽取

#### 2.1.4 快速入口
- **入口数量**: 4个
- **入口内容**:
  1. 书籍大全 → 跳转书籍列表页
  2. 金句库 → 跳转金句列表页
  3. 我的收藏 → 跳转个人中心收藏区
  4. 播放历史 → 跳转个人中心历史区
- **图标**: 彩色渐变圆形图标

#### 2.1.5 最新讲解
- **样式**: 横向滚动卡片列表
- **卡片内容**: 书籍封面、书名、讲解时长
- **交互**: 点击进入书籍详情

---

### 2.2 书籍列表页 (page-books)

#### 2.2.1 筛选栏
- **位置**: 页面顶部
- **筛选项**: 全部、经典名著、科幻小说、历史文学、哲学思考、商业经济、心理励志
- **交互**: 点击切换筛选状态，列表实时更新

#### 2.2.3 书籍网格

- **卡片内容**:

  - 标签（讲解音频、精选）

## 三、数据模型

### 3.1 书籍 (Book)

```typescript
interface Book {
  id: number;           // 书籍ID
  title: string;        // 书名
  author: string;       // 作者
  category: number;     // 分类ID
  duration: string;     // 讲解时长
  color: string;        // 封面背景色
  featured: boolean;    // 是否精选
  intro: string;        // 内容简介
}
```

### 3.2 金句 (Quote)

```typescript
interface Quote {
  id: number;           // 金句ID
  content: string;      // 金句内容
  author: string;       // 作者
  bookName: string;     // 书籍名称
  bookId: number|null;  // 关联书籍ID
  playCount: number;    // 播放次数
}
```

### 3.3 用户 (User)

```typescript
interface User {
  id: string;           // 用户ID
  nickname: string;     // 昵称
  avatar: string;       // 头像URL
}
```

### 3.4 播放历史 (PlayHistory)

```typescript
interface PlayHistory {
  id: number;
  title: string;
  author: string;
  progress: number;    // 播放进度百分比
  cover: string;        // 封面
  lastPlayTime: Date;   // 最后播放时间
}
```

