# 微信云开发数据库配置指南

## 一、开通云开发

### 1. 在微信开发者工具中开通
1. 打开微信开发者工具
2. 点击顶部菜单 **工具** → **构建 npm**（如果提示）
3. 右键点击项目根目录 → **更多设置** → **项目设置**
4. 勾选 **启用云开发** 选项
5. 系统会自动创建云开发环境

### 2. 获取云环境ID
1. 打开微信开发者工具
2. 点击顶部 **云开发** 按钮
3. 在云开发控制台中，复制 **环境ID**（格式如：`production-xxx`）

### 3. 配置环境ID
编辑 `miniprogram/app.js`，更新 `cloudEnv` 配置：

```javascript
globalData: {
  // ...
  cloudEnv: '你的云环境ID',  // 例如：production-1a2b3c
}
```

## 二、创建数据库集合

在云开发控制台中创建以下集合：

### 1. books（书籍集合）

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| _id | string | 文档ID（自动生成） | - |
| title | string | 书名 | "红楼梦" |
| author | string | 作者 | "曹雪芹" |
| category | number | 分类ID（1-7） | 1 |
| coverColor | string | 封面颜色 | "#e74c3c" |
| description | string | 书籍简介 | "中国古典小说巅峰之作" |
| audioUrl | string | 音频URL | "" |
| duration | number | 时长（秒） | 3600 |
| isHot | boolean | 是否热门 | true |
| createTime | number | 创建时间戳 | Date.now() |
| updateTime | number | 更新时间戳 | Date.now() |

### 2. quotes（金句集合）

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| _id | string | 文档ID（自动生成） | - |
| content | string | 金句内容 | "满纸荒唐言，一把辛酸泪。" |
| author | string | 作者 | "曹雪芹" |
| bookName | string | 书籍名称 | "红楼梦" |
| bookId | string | 关联书籍ID | "书籍的_id" |
| playCount | number | 播放次数 | 5200 |
| likeCount | number | 点赞次数 | 1200 |
| createTime | number | 创建时间戳 | Date.now() |

## 三、部署云函数

### 1. 安装依赖
进入每个云函数目录，安装依赖：

```bash
cd miniprogram/cloudfunctions/getBooks
npm install

cd ../getQuotes
npm install

cd ../getBookDetail
npm install

cd ../searchBooks
npm install

cd ../searchQuotes
npm install
```

### 2. 上传云函数
1. 在微信开发者工具中
2. 右键点击每个云函数文件夹
3. 选择 **上传并部署：云端安装依赖**
4. 等待部署完成

### 需要部署的云函数：
- `getBooks` - 获取书籍列表
- `getQuotes` - 获取金句列表
- `getBookDetail` - 获取书籍详情
- `searchBooks` - 搜索书籍
- `searchQuotes` - 搜索金句

## 四、添加初始数据

### 方式一：在控制台手动添加

1. 打开云开发控制台
2. 进入 **数据库** 标签
3. 选择 **books** 集合
4. 点击 **添加记录**，输入以下示例数据：

```json
{
  "title": "红楼梦",
  "author": "曹雪芹",
  "category": 1,
  "coverColor": "#e74c3c",
  "description": "中国古典小说巅峰之作，以贾宝玉和林黛玉的爱情悲剧为主线，描绘了一个大家族的兴衰历程。",
  "audioUrl": "",
  "duration": 3600,
  "isHot": true,
  "createTime": 1700000000000,
  "updateTime": 1700000000000
}
```

### 方式二：批量导入

1. 准备 JSON 文件格式的数据
2. 在控制台选择集合
3. 点击 **导入**，选择 JSON 文件

## 五、测试验证

1. 启动小程序开发者工具
2. 打开控制台，查看日志输出
3. 进入首页，应该能看到从云数据库加载的书籍
4. 如果显示 "暂无书籍数据"，检查：
   - 云开发是否开通
   - 集合是否创建
   - 是否有数据

## 六、常见问题

### Q1: 云开发按钮是灰色的？
确保已开通云开发服务。进入微信公众平台，在「开发」→「开发者工具」中开启云开发。

### Q2: 数据加载失败？
1. 检查网络连接
2. 检查云环境ID是否正确
3. 查看控制台错误信息
4. 确保云函数已部署

### Q3: 云函数调用失败？
1. 检查云函数是否部署成功
2. 检查云函数依赖是否安装
3. 查看云开发控制台的云函数日志

### Q4: 如何备份数据？
在云开发控制台中，可以导出集合数据为 JSON 格式进行备份。
